## An acceptance criterion whose only verb is "is stated as such" is unobservable — name the artifact or delete it

A criterion that requires a fact to be *stated* without naming where (prose, the
PRD, nobody) cannot be checked, and it is usually a limitation already carried
normatively by a Deferred bullet or a sibling capability's criterion. Delete it and
let the canonical home carry it; a capability with two genuinely observable criteria
still meets the 2–4 bar. Same move for a standalone "no automated case can reach
this site" criterion — hang it as a trailing clause on an observable criterion and
leave the Risks bullet as the single canonical statement.
