## Where one capability enumerates N classes, the capability that covers them must reach all N or narrow its headline

When a capability names a closed set of cases (classes, shapes, failure kinds), any later
capability whose headline quantifies over "every" such case must have a criterion touching
each one — grouped into a single criterion listing them, which is the consolidation rule, not
a criterion each. If a case is genuinely not worth covering, narrow the headline so the set it
quantifies over is the set it delivers, rather than leaving the gap under a universal claim.
