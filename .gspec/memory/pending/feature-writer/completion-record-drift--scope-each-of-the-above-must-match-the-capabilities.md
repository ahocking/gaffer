## Check every "each/every/all of the above" in Scope against the capability that actually delivers it

A blanket quantifier in Scope is read as a promise, and it routinely over-promises
the coverage capability — committing verification for items the capabilities
themselves say only a human reviewer can gate. Narrow the quantifier to the subset
the delivering capability names ("for each detection and classification judgement
above"), rather than leaving a line that invites the very pin the Risks section
declines.
