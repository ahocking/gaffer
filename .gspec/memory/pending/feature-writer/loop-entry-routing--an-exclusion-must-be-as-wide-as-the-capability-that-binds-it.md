## Write each Scope/Out bullet at the same width as the capability clause that binds it

An exclusion narrower than the capability it mirrors silently permits edits the
capability forbids — and the qualifier that narrows it ("…'s decision table",
"…'s schema", "…'s public methods") reads as precision while being the defect.
After drafting Scope/Out, pair each bullet with the criterion that constrains
the same surface and widen the bullet until they name the same thing; the
narrower wording is almost always also the longer one, so the fix costs nothing.
