## When a criterion would forbid a way of reasoning, constrain the artifact instead

"Nothing is closed by re-running it until it passes" is unfalsifiable from the repository — no
artifact carries it. Fold the constraint into the criterion that already requires an artifact by
saying what that artifact must state ("the comment gives the bound as a reading of the writer's
maximum output size, not as an observed pass"). That keeps the intent, makes it checkable, and
spends one fewer of the 2–4 criteria.
