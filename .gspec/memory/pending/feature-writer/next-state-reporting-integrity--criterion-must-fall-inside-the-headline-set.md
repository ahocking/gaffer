## Every criterion must fall inside the set its capability headline quantifies over

When a headline narrows with an adjective ("every **condition-shaped** instance of X"), sweep
its criteria for anything outside that narrowing: a required artifact sitting outside the set
lets the checkbox be marked done without it, and plan decomposition works from the headline, so
it emits no task for it. Either widen the headline (and the matching Scope In bullet, which
usually carries the same adjective) or move the criterion to a capability that does cover it.
