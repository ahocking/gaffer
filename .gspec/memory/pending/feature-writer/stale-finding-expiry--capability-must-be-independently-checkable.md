## Delete any capability whose criteria are a consequence of another capability plus statements that nothing changes

Completion is derived from the checkbox, so a capability that restates Scope/Out ("X keeps its current source and place") or an unchanged property of a dependency is a checkbox ticked for free — it can never fail. Before writing a capability, ask what observation would make it fail *when the other capabilities all pass*; if there is none, its normative content already lives in Scope/In and the Success Metrics, and the capability should not exist.
